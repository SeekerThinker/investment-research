# A/H 投资研究周报 — 2026-W37

> 覆盖窗口：2026-09-05 至 2026-09-11（截至 9 月 11 日上午；当日A/H市场尚未收盘，市场价格比较尽量使用 9 月 10 日收盘或已确认数据）。面向A股与港股通。本文为研究记录，不构成买卖指令或收益承诺。

## 一、过去一周最重要的全球事件与中国资产传导

### 1. 中东供应冲击升级，Brent重新站上100美元并逼近110美元
9月10日Brent结算价107.63美元/桶，9月11日上午一度约109.97美元/桶；Reuters称本周累计涨幅接近13%。霍尔木兹海峡及红海航运风险、油轮袭击、也门港口局势与沙特能源设施风险共同抬升实物供应约束。OPEC 8月产量环比减少约64万桶/日。

**传导链：** 中东冲突 → 原油/运费/保险成本上升 → 中国进口能源成本与PPI抬升 → 上游油气现金流相对改善；炼化、航空、化工、运输及部分制造业成本承压 → 全球利率预期重新偏鹰，对港股成长估值形成压制。

**A/H观察：** 中国海油 600938.SH / 00883.HK、中国石油 601857.SH / 00857.HK优先于炼化链；油运仅作为高波动事件链观察。

### 2. 中国8月PPI同比+3.8%、CPI同比+0.8%，上游通胀与终端需求偏弱并存
国家统计局数据显示，8月CPI同比+0.8%、环比+0.4%；PPI同比+3.8%，其中能源与上游原材料贡献明显。核心矛盾不是“全面通胀”，而是**上游成本冲击快于终端价格传导**。

**传导链：** 能源与资源品上涨 → PPI上行 → 资源品利润改善、弱议价中下游毛利受压；CPI仍低 → 居民端需求与终端提价能力并不强。

### 3. 中国8月出口同比+25%、进口+28.2%，高科技与AI相关产品仍是外需支撑
海关数据经Reuters报道显示，8月出口同比增长25%，进口增长28.2%，贸易顺差1190.9亿美元，高科技出口同比增长42.9%。外需继续托底工业，但也意味着经济结构仍偏“制造/出口强、内需偏弱”。

**传导链：** 全球AI/高科技资本开支 → 中国电子、半导体、设备、汽车等出口 → 制造链订单韧性；但贸易摩擦与汇率、关税仍是尾部风险。

### 4. 中国AI芯片因HBM短缺提价，国产算力进入“需求强 + 成本瓶颈”阶段
Reuters称华为、寒武纪及其他国产AI芯片厂商因HBM短缺与出口限制提高报价。寒武纪下一代690芯片报价据报道上调20%-30%，华为昇腾950DT报价较此前提高约20%-50%。

**传导链：** AI算力需求强 → HBM成为约束 → 加速卡售价和成本同时上涨 → 不能简单推导“涨价=利润率提升”；真正需要验证的是议价能力、毛利率和国产存储/先进封装资本开支。

### 5. 炎融科技（Enflame）科创板上市，国产GPU估值热度显著上升
公司IPO募资61.2亿元，发行价142.18元，首日盘中涨幅接近200%。但公司仍处亏损状态且首日可流通比例低，价格发现可能被供需结构放大。

**研究意义：** 可作为国产AI芯片一级/二级市场估值锚，但不应把首日涨幅外推为整个国产GPU板块的确定性基本面改善。

### 6. 中美讨论约300亿美元商品互惠降税，贸易关系出现“小范围缓和”窗口
AP报道，中美正在讨论对约300亿美元商品实施互惠关税削减，并可能与9月24日高层会晤窗口衔接。

**传导链：** 若商品清单落地 → 部分出口制造风险溢价下降 → 人民币与风险偏好边际改善；但规模相对整体双边贸易有限，不能外推成全面贸易正常化。

### 7. Apple正式进入折叠屏，华为/小米同步发布新品
Apple折叠iPhone Duo、华为Mate XT2、小米新折叠旗舰共同推动品类扩容。华为Mate XT2于9月12日开售。

**传导链：** 多品牌新品 → 折叠屏渗透率提升预期 → 柔性显示、精密结构件、铰链、玻璃/盖板等需求；但A股映射需以真实供应份额和订单验证，不能只按概念扩散。

### 8. 全球债券收益率上行，油价使主要央行重新面对加息压力
Reuters 9月11日报道，美国10年期国债收益率接近5%，市场重新提高对Fed加息的定价，ECB已加息，BOJ也面临更高通胀压力。

**中国资产影响：** 美债高收益率 + 强美元倾向压制港股成长估值；人民币若仍保持韧性可部分缓冲。资源、金融与高现金流资产的相对吸引力上升。

## 二、本周重点投资研究机会

### 机会1：油气上游的盈利预期再定价
**状态：强化观察。**

- 核心逻辑：Brent>100美元且供应风险从“情绪溢价”转为更持久的航运/出口约束。
- 代表标的：中国海油 600938.SH / 00883.HK；中国石油 601857.SH / 00857.HK。
- 催化窗口：数日—2周。
- 关键验证：Brent是否持续>100；霍尔木兹通行量；沙特/伊朗出口；国内进口原油现货溢价。
- 估值/拥挤：资源板块短期关注度已提升，需防止在油价冲高后追逐单日涨幅。
- 证伪：停火/航运快速恢复，Brent持续跌回90美元以下。
- 关联：THM-001 / HYP-20260911-001 / CAT-20260911-001。

### 机会2：国产AI算力的“议价能力”而非单纯涨价
**状态：观察。**

- 核心逻辑：HBM短缺证明AI算力需求仍强，但成本与售价同步上升。
- 直接观察：寒武纪-U 688256.SH。
- 二阶观察：北方华创 002371.SZ、中微公司 688012.SH；前提是国产存储/先进封装CAPEX得到招标与订单验证。
- 催化窗口：1周—1季度。
- 关键验证：产品报价、出货量、客户CAPEX、毛利率、国产HBM扩产。
- 证伪：采购推迟、涨价不能覆盖成本、资本开支未落地。
- 关联：THM-002 / HYP-20260911-002 / HYP-20260911-003 / CAT-20260911-002。

### 机会3：出口高景气中的高科技制造链
**状态：新观察。**

8月出口同比+25%、高科技出口增长42.9%，说明外需仍偏强。研究重点不是“所有出口股”，而是订单、价格和全球资本开支可持续的环节。

- 观察方向：半导体设备、AI基础设施零部件、汽车/零部件、部分高端制造。
- 催化窗口：1—3个月。
- 关键验证：9月出口订单、美国/欧洲关税政策、企业海外订单与毛利率。
- 风险：贸易摩擦升级、汇率变化、海外需求放缓。

### 机会4：PPI再通胀下的利润分化
**状态：观察。**

- 上游：油气、有色等具价格传导能力的资源品相对受益。
- 中下游：航空、炼化、部分化工和运输可能面临成本挤压。
- 催化窗口：2周—2个月。
- 证伪：能源价格快速回落、9月PPI重新转弱。
- 关联：THM-003 / HYP-20260911-004 / CAT-20260911-003。

### 机会5：折叠屏品类扩容，但只研究真实供应链
**状态：观察，置信度中。**

- 候选：京东方A 000725.SZ、立讯精密 002475.SZ、蓝思科技 300433.SZ。
- 催化：华为Mate XT2 9月12日开售；Apple折叠产品销量与供应链爬坡。
- 关键验证：供应份额、订单、单机价值量、销量。
- 证伪：销量不及预期或A股公司没有新增订单。
- 关联：THM-004 / HYP-20260911-005 / CAT-20260911-004。

### 机会6：中美小范围关税削减的事件窗口
**状态：低置信观察。**

- 逻辑：互惠降税若覆盖中国优势制造品，出口链风险溢价可能下降。
- 催化窗口：至9月24日前后。
- 关键验证：官方商品清单、执行日期与规模。
- 证伪：谈判延期、清单规模过小或不覆盖A/H主要产业链。
- 关联：THM-005 / HYP-20260911-006 / CAT-20260911-005。

## 四、本周优先级排序

1. **油气上游 / 中东供应冲击** — 信息最直接、基本面传导最短，但波动也最大。
2. **国产AI算力 + HBM瓶颈** — 产业趋势强，重点看利润率和国产存储CAPEX，而非只看涨价。
3. **PPI再通胀的行业利润分化** — 可作为跨行业配置研究框架。
4. **高科技出口链** — 8月数据强，但需警惕贸易摩擦与高基数。
5. **折叠屏真实供应链** — 事件确认度高、个股映射确认度低。
6. **中美互惠降税窗口** — 潜在正面，但当前规模和清单不确定。
