# Source Policy

本文件定义投资研究中的信息来源优先级、证据属性与可信度规则。原则是先事实、后解释；先一手来源、后媒体转述；重大投资判断尽量进行独立交叉验证。

完整研究方法见 [`research-os.md`](./research-os.md)。

## 来源优先级

1. **A级：一手官方来源**——政府、央行、监管机构、交易所、上市公司正式公告、法定披露、官方统计数据库、客户/供应商正式文件。
2. **B级：高质量主流财经媒体**——具有成熟采编与事实核验机制的国际或国内主流财经媒体。
3. **C级：行业机构与专业研究来源**——行业协会、研究机构、供应链调研、券商公开研究等；需注意方法、样本和利益冲突。
4. **D级：未经充分核实的信息**——匿名消息、社交媒体、论坛、二手转述、传闻。此类来源不能单独支撑高置信投资判断。

## 证据属性 F / I / S / R

来源等级回答“信息从哪里来”，证据属性回答“这句话是什么性质”。两者必须分开。

- **F — Fact**：已确认事实。优先由A/B级来源支撑；核心F尽量回到原始文件。
- **I — Inference**：由事实通过产业、工程或财务逻辑推导的结论；必须保留因果链。
- **S — Scenario**：未来渗透率、ASP、市占率、良率、利润率、CAPEX、盈利、估值等情景假设。
- **R — Rumor / Unverified**：未确认客户、订单、扩产、良率、价格、市场份额、AI/HBM收入等；不得单独进入核心盈利预测。

无法确认时明确写：`待验证 / 尚无可靠公开数据`，不得用推断填补事实空白。

## 使用规则

- 重大政策、监管、公司事件优先回溯至A级原始文件。
- 重大投资判断尽量由至少两个彼此独立的可靠来源交叉验证；单一A类一手文件可以确认其自身披露事实，但不能自动证明外延推断。
- 每个核心判断尽量标记 F/I/S/R；不要把事实、解释、推断、情景混写成同一种确定性。
- 记录事件发生时间与信息首次公开时间，避免事后信息污染。
- 对修订、澄清、撤回或冲突信息保留历史痕迹，不删除旧判断。
- 无法验证的信息必须降低可信度与研究优先级。
- 旧研报、历史静态资料可以支持长期机制和历史比较，但不得以过期价格、市值、客户、订单或产能状态支撑“当前投资价值”。
- 新闻只有在能够改变出货、渗透率、ASP/Mix、市占率、合格产能、良率、利润率、CAPEX、CFO/FCF、盈利预测、风险概率或估值体系时，才应升级为正式研究事件；纯热度只作为背景。

## 商业化兑现阶段

对产业/公司判断同时维护 V0–V5；纯宏观/政策事件可用 `N/A`：

`V0产业逻辑 → V1技术机制 → V2产品验证 → V3客户验证 → V4商业化放量 → V5利润/现金流确认`

V0/V1不得使用与V4/V5同等确定性的利润假设。
