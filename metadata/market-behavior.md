# Market Behavior Layer

本文件定义量价、相对强弱、注意力和基本面验证之间的关系。目标不是做机械技术分析，而是识别“价格发现领先于公开确认”的阶段，并衡量价格与基本面之间的错位。

## 1. 四路研究入口

研究系统不再以 NEWS 作为唯一入口，而是四路并行：

1. **Market Behavior**：价格、成交、相对强弱、波动和拥挤度。
2. **Leading Indicators**：产业需求、价格、库存、CAPEX、订单、认证、产能、良率等。
3. **Narrative / Attention**：新闻密度、机构关注、市场叙事扩散。它只代表注意力，不代表事实。
4. **Verification / Confirmation**：公司公告、交易所、监管、官方统计、客户/供应商正式材料，以及最终收入、利润、CFO/FCF确认。

四路信号最终进入 EVT / THM / HYP / CAT / securities，并由 Model Audit 约束。

## 2. Market Phase：M0–M5

Market Phase 描述市场行为和信息扩散阶段，不代表必然上涨或下跌，也不允许只凭单日K线判断。

- **M0 潜伏/早期异动**：相对强弱、成交或波动开始异常，但公开叙事很弱，基本面证据通常仍在 V0–V2。
- **M1 发现**：量价异常具有持续性，产业线索开始出现，但市场关注仍有限。
- **M2 扩散**：价格和注意力加速，媒体/机构叙事明显增加，基本面可能仍未充分确认。
- **M3 拥挤**：高相对涨幅、高成交/换手、高注意力和较一致叙事同时出现；价格可能明显领先基本面。
- **M4 验证**：正式订单、认证、公告、经营数据或财务证据开始确认；此阶段价格可能继续上涨，也可能进入震荡消化。
- **M5 兑现/背离**：V5财务与现金流已经确认，重点观察“新增正面信息还能否推动价格”。如果基本面改善但价格钝化或转弱，视为兑现后背离风险，而不是自动认定资金退出。

阶段可以前进、停滞或回退。正式 `market_phase` 必须结合量价、叙事、V阶段和基本面，不由单一技术指标自动决定。

## 3. Price–Fundamental Gap

用于描述价格相对基本面兑现的领先程度：

- **PF-2**：基本面显著领先价格。
- **PF-1**：基本面轻度领先价格。
- **PF0**：价格与基本面大体同步。
- **PF1**：价格轻度领先基本面。
- **PF2**：价格显著领先基本面。
- **PF3**：价格极度领先基本面，且存在高拥挤/兑现前风险。
- **未判定**：证据不足。

Price–Fundamental Gap 是研究判断，不是收益预测。高 PF 不等同于应卖出，低 PF 也不等同于应买入。

## 4. 量价指标

机器层只计算可复现指标并给出 `phase_hint`，不直接形成投资结论：

- 5D / 20D 绝对收益。
- 5D / 20D 相对基准收益。
- 最新成交量 / 前20日平均成交量。
- 最新成交量在近60日的分位。
- 距离20日高点。
- 20日年化实现波动率。

A股默认以沪深300作为相对基准；港股默认以恒生指数作为相对基准。机器行情源不是交易所官方源，因此关键结论需与交易所/可信市场数据交叉验证。

## 5. Crowding 与 Distribution Risk

`crowding` 统一为：`低 / 中 / 高 / 极高 / 未判定`。

拥挤度主要用于描述价格与成交行为，不等于“主力持仓”。不得把成交量放大机械解释为大资金吸筹或出货。

`distribution_risk` 统一为：`低 / 中 / 高 / 极高 / 未判定`。高风险通常需要多个条件共同出现，例如：

- 价格已经明显领先基本面；
- 成交量/换手位于高分位；
- 叙事和媒体关注高度一致；
- 领先指标停止改善；
- 盈利预测或V阶段没有继续上修；
- 新增正面信息无法推动价格创新高，或利好后相对强弱转差。

系统将其表述为“分配/拥挤反转风险”，不得无证据断言内幕交易或媒体与资金协同行动。

## 6. 研究决策顺序

正式研究按照以下顺序组合信息：

`Market Behavior → Leading Indicators → Narrative/Attention → Verification → Fundamental Confirmation → Model Audit`

官方信息源的角色主要是验证和确认，并非唯一的机会发现入口。媒体的角色主要是发现与注意力测量，也不是事实层。

## 7. 数据与判断分离

- `data/market/`：机器行情快照和健康状态，可覆盖最新值。
- `tracking/market-behavior.md`：研究层对 M0–M5、PF Gap、拥挤和分配风险的可审计判断。
- `index/securities.md`：保存每个研究标的当前市场阶段摘要。
- 日报/周报/月报：记录阶段迁移及其原因，历史报告不得事后改写。

机器 `phase_hint` 只能作为提示。正式阶段必须保留证据、解释和下一验证条件。
