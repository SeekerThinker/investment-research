# 多期限资本开支 → 公司现金流：条件性研究方法

> **定位**：本项目的专业研究方法补充，适用于确有资本开支传导关系的 AI 基础设施、半导体、存储、设备材料及其他重资产产业；不是新的所有者投资信念、实时行情、股票推荐或必选报道主题。依据所有者提供的《投研分析框架》（标为 Research OS v6.5）及《投研标的》《近期投研标的》（后者标注 2026-07-13）的可迁移方法，由编辑者独立整理；未对附件中的市场数字、来源、预测或个股判断作外部核验，也未将附件原文复制入公开仓库。上层见 [`../philosophy/core-beliefs.md`](../philosophy/core-beliefs.md) 的 P11；通用证据与估值规则仍以 [`research-os.md`](research-os.md)、[`source-policy.md`](source-policy.md)、[`long-horizon-value-policy.md`](long-horizon-value-policy.md) 为准。

## 1. 四个期限，各回答不同问题

| 期限 | 研究用途 | 必须核查的反面证据 |
| --- | --- | --- |
| 未来约 1 年 | 已批准预算、采购/招标、订单交付和现金支付的近期节奏；与本期盈利确认分开 | 预算未拨付、订单取消、招标延后、验收推迟 |
| 未来约 3 年 | 已披露在建产能、交付/认证进度、客户采用及可兑现的公司收入、成本与利润路径 | 扩产尚未承诺、供需反转、客户导入受阻、竞争者抢占份额 |
| 未来约 5 年 | 需求可持续性、产能消化、替换/维护性 CAPEX、竞争与现金回报的中期范围 | 库存积压、价格下滑、利用率不足、增长资本支出吞噬 FCF |
| 约 10 年技术路线 | 仅做替代技术、标准、效率、能源约束、产业架构和竞争寿命的**方向性压力测试** | 现有环节被绕开、每单位算力成本/材料单耗下降、技术路径失效 |

这些期限是**提问框架，不是必须编造四组数字**。长期基线仍按已有 20 年分段与 50 年竞争寿命敏感性研究；10 年技术演绎不产生可靠的远期绝对 CAPEX 数值，也不能自动赋予高终值倍数。只有具备可比来源、单位、时点和覆盖范围的数据，才画可量化 CAPEX 曲线；否则列为未量化方向与下一核实点。

## 2. 从行业投入到企业所有者回报：每一层都可中断

`实际应用需求/单位经济性 → 已披露及实际执行的上游 CAPEX → 项目进度与产品路线 → 行业有效供给/库存/现货与合约价 → 可服务市场（SAM）和具体瓶颈 → 公司已验证产品、单位价值量/单耗、客户采用和实际份额 → 合格产能与交付 → 收入 → 毛利、费用和税 → 净利润 → CFO → 维护/增长 CAPEX 与营运资本 → FCF → 在同日价格/股数与风险条件下检验权益价值`。

- **产业强 ≠ 公司受益 ≠ 股东回报**：CAPEX 是支出意向或投入，不等于被研究公司已经拿到订单；TAM/SAM 不等于公司收入；收入不等于净利润，净利润也不等于可分配现金流。检验订单公告/合同（披露允许的范围）、客户量产、收入占比、毛利率、回款、库存、应收、在建工程及资本开支。不得猜测保密客户和采购金额。
- **周期反证**：对存储、PCB/CCL、光通信、电力设备等具体周期性业务，结合可获得的渠道库存、现货与合约价格、客户拉货/砍单、产能利用率和供应释放，判断名义 CAPEX 能否兑现；没有数据时写“待复核”，不因行业扩产公告直接上调盈利或长期价值。
- **商业化证据**：沿用 Research OS 的 V0–V5 和既有 A/B/C 催化框架；补充记录送样→认证→小批量→批量供货→财报及现金流兑现的真实阶段，逐次保存上修、下修或证伪条件。不要把附件的 P0–P5 证据标签误当本仓库 P01–P11 投资原则，也不要另造与 V0–V5 冲突的正式等级。
- **限制性风险**：将关键部件/材料可替代性、出口管制及许可适用性、客户合规、供电与融资约束列为独立检查项。只有基于有日期、适用主体和产品的可靠文件才能判定具体限制；政策表态不等于已生效限制，传闻不等于确定断供。无法核实关键投入时，相关盈利/估值保持“待复核”，不可用其他利好分数抵销。

## 3. 估值必须与现金流和股数口径自洽

有证据时可展示**一个注明假设和概率不确定性的工作路径**，列出支持其上修/下修的可观察触发因素，同时保留现行保守/基准/乐观情景与折现率、终值、份额和资本支出的敏感性测试；不得因附件一句“不使用三情景”而废止现行安全边际纪律。

- 从 FCFF/WACC/EV 或 FCFE/股权成本/权益价值选择一致路线，将未来各期现金流及第 N 年终值**分别折现到同一估值日**。终值只计一次；净债务、非经营资产、少数股东权益及完全摊薄股份按所选口径处理，防止净利润与 FCF、债务、再投资重复计入。`未来 N 年累计未折现 FCF + N 年后的未折现终值` **不能直接当作今天的股权市值**。
- 采用 PE 交叉检查时须说明适用盈利年度、盈利质量、资本密集度、增长久期和终值假设；没有订单、份额、现金流或股数证据，不给“高可能性”目标市值或伪精确潜在涨幅。投资假设即使乐观，也不得跳过资本支出、营运资本、现金流和永久损失反证。
- 配股/定增、可转债转股、股份回购、股份支付及其他股本变化，可能改变**每股价值**而非同等改变企业整体经营价值；重新核对完全摊薄股数及融资资金用途。旧股价、旧总股本与新目标价值不可跨日混算。单日回撤或减持结束只能提示价格/供给变化，不自动提升企业价值。

## 4. 可复用的增量更新卡（用于后续真实新研究）

1. **截止时点与资料状态**：报告时区、资讯披露日、最近完成交易日/盘中时点、货币、股数及来源 URL；明确 F/I/S/R 与哪些是旧假设。
2. **新增变化**：相对上一版本的实际增量；区别“新事实”“市场价格变动”“模型假设变化”“仅重新排版”。缺少新事实时不强行改变旧预测。
3. **1/3/5 年投入与 10 年技术路线**：各期限证据、未执行承诺、可观察不利因素；不具备数据的期限留空并标原因。
4. **公司因果桥**：具体产品/客户验证阶段、SAM、单位价值量、份额、产能、收入、利润、CFO/FCF及资本需求；每个关键未知项及下一来源。
5. **资本结构和硬风险**：股本变化、锁定期/供给、资金使用效率、适用监管约束和可替代方案，标明已确认或待核验。
6. **判断更新**：哪些假设保持、上修/下修或证伪及其触发证据；是否有同日可核对市场预期与权益价值，否则写“预期差未判定”。不必给机械排名、买卖指令或个人仓位。

**使用边界**：这是深化重点专题和周/月复盘的检查法，不要求每日 7–10 条资讯全部做完整模型；全市场广扫描、双主线、历史报告不可变和所有内容免费阅读保持原样。用户提供的 2026 年 7 月标的表与 7 月 13 日盘中更新仅是**历史研究样本**，其中股价、目标市值、榜单、仓位及买卖阈值不得搬入 `latest/`、当前 `index/`/`tracking/` 或公开首页充当今日结论；若未来要研究相关公司，重新从一手披露和同日行情独立核验。
