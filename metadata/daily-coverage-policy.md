# 全市场独立日报规范：广扫描、精发布、机遇与风险双主线

适用于后续 A/H 日报、盘中增量更新及可变的 `latest/daily.md` 和免费首页。以 `philosophy/` 和 `metadata/philosophy-integration.md` 为上游，结合 `news-investment-impact-policy.md`、`long-horizon-value-policy.md`、`research-os.md` 和来源纪律。**日报精选限制只约束日报，不得删减或遮蔽周报、月报首页栏目。** 历史不可变报告不回写。

## 1. 后台依然独立、全面扫描

- 以本期截止前约24小时公开事实和最近已经完成的真实A/H交易时段为起点，标北京时间截止、消息披露日、A/H各自真实交易日期与数据源健康；不能将旧闻、过时收盘或未经核实行情包装为新事实。不先强制复核前日报，也不事后补造缺失报告。
- 核查九面：宏观政策/货币/利率/汇率，A股指数成交广度轮动，港股恒科南向，金融地产消费医药，科技AI半导体互联网，能源材料公用，制造汽车机械航运外贸供应链，公司公告财报订单风险，以及海外股债商品地缘传导。全市场范围不可用已有少数跟踪股代替。无可核验更新/数据滞后/未覆盖须在 `## 覆盖与数据缺口` 如实说明。
- 优先一手公司/交易所/监管/官方数据；媒体与NEWS或机器hint仅供发现，重要数据交叉验证。记录有意义但未被精选的来源和审查状态；未入选不等于不重要。F/I/S/R明确分层。

## 2. 两类投资关注方向与重大预期差

- **投资机遇**关注能够核实的经营改善、未来FCF增强、阶段性缩量回撤与潜在价值错位。研究“市场预期是什么／新事实显示什么／公司真实现金流增量和竞争寿命怎样／什么条件才成立”。未取得真实预期、同日价格、可审计财报和估值区间，不得宣称重大预期差已证实、收益率极高、股票已明显低估或提供机械买卖建议。
- **风险规避**关注重大现金流和永久资本损失通道，如融资与债务到期、终值过度乐观、需求破坏、成本转嫁失败、稀释、治理和流动性。研究可能被低估的负面情景、风险触发及反证；缺现价模型则仅写潜在风险，不能虚构极大亏损比例或必然下跌。
- 同一事实可能对不同受益方与受损方、短期市场和长期FCF形成相反影响。分组按**当前最值得核查的主要投资传导**，不是涨跌预测；重要反向事实不得隐藏，保存在全文或具体验证条件中。不要求每条机械地同时填写「机会」「风险」两栏，不为凑数编造任何一组。政策分析仅讨论有来源的经济机制，不作政治价值评判。
- 全市场线索先按共同因果链归并，再**通常选7—10条、总数不超过12条，约5—7个跨组投资面向**；密度不足可更少。挑选考虑时效、事实可证程度、FCF/行业利润或永久损失的传导、现价预期证据、独立信息增量和验证条件。不能仅按热门程度、机械分数或来源顺序取前12，也不能用市场热度当作高收益依据。

## 3. 新日报写法与首页发布

- `reports/daily/YYYY-MM-DD.md` 的 `## 今日全市场资讯速览` 和 `latest/daily.md` 的 `## 今日核心结论` 采用研究者**显式标记**的 `【投资机遇·面向】` 或 `【风险规避·面向】`。每一项一条Markdown物理行以供安全提取，正文排版在网站上拆为独立视觉行：机遇写`事实：｜传导：｜潜在预期差：｜成立条件：｜强度/期限：｜验证：`；风险写`事实：｜传导：｜潜在预期差：｜风险触发：｜强度/期限：｜验证：`。不得让一条同时强制出现成立条件和风险触发，也不得用套话填充。详细证据/双向影响和来源应存于可免费阅读的本期全文。
- 本期最新摘要与不可变完整报告的日期、事实和推论级别一致。现有已发布全文可能仍采用旧版逐条双向格式，**只允许整理可变 `latest/`，不得回写旧 `reports/`**。网站精选程序只验证研究者亲自作出的两个分类和条数，不自己推测新闻究竟偏机会还是偏风险；每条详情仍打开对应已发布全文。市场行为与风险详细列表保留在全文，避免首页在两组之外额外堆叠日报卡片。
- 站点首页在这两个日报分组之后，**必须独立保留周报、月报及各自最新摘要**；它们不受日报的12条限制，旧版周/月写法可继续阅读。白色背景、单列纵向阅读，分行排版只重排已有事实，不生成新研究结论。
- 正文其他栏目：`## 今日市场行为观察` 留关键3—5条有数据的量价和反例；`## 今日主要风险与验证` 约3—5条独立风险；`## 深度研究` 1—3项真正重要的现金流机制；`## 长期价值与缩量回撤观察` 只在基本面/复权量价/20年FCF主情景与50年压力测试有足够根据时给合格候选；`## 覆盖与数据缺口` 交代九面扫描、未入选材料和来源故障。数量都是编辑目标，禁止凑数。

## 4. 发布前审核

核实候选两组是否互斥、总数≤12、面向≤7、每条日期来源/具体传导/潜在预期差证据边界/成立条件或风险触发/强度期限/下一验证是否可复核；是否误把历史收盘当实时，或将新闻热度当现金流？是否保留重大反例和不足证据？周报月报首页栏目是否完好？价格、债务和FCF数据缺失时写待估值、不捏造上涨/亏损幅度。执行Repository Integrity Audit，写前再次核实公开仓库权限；既有历史报告和失败/证伪记录不可篡改。仓库PUBLIC、已发布研究免费、自愿赞助的政策不变；不得泄露凭据、私人财务或无再分发权的内容。
