# 逐条资讯的投资影响映射规范（News → Investment Implications）

适用于**今后新发布**的 A/H 全市场日报、盘中增量更新、周报、月报，以及从这些报告提取的免费首页资讯。网站不应只复述新闻：凡以独立资讯条目发布的事实，都要明确解释它如何影响资产定价、行业经营、公司现金流或风险；证据不足时明确写“映射待验证/影响无法量化”，而不是编造赢家、目标价、机会或交易信号。与 `research-os.md`、`daily-coverage-policy.md`、`long-horizon-value-policy.md`、`source-policy.md` 的事实分层、独立日报、长周期价值、来源和不可变历史规则并行。

## 1. 每条资讯必须回答的六件事

1. **发生什么（F）**：事件/正式披露与准确日期、公开来源 URL；传闻为 R，分析为 I，情景为 S；不得把新闻稿预测当作已实现的经营事实。
2. **影响谁、方向如何**：分别审视全市场/宏观、A/H 主要风格或资产、受益与受损行业、可核验暴露的具体公司。逐层写明 `正面 / 负面 / 双向分化 / 方向未定 / 无可证实直接影响`；允许不同时间、不同对象的方向相反。无可靠公司暴露时止于行业，不随意点名股票，更不可把供应链“相关”当成已获订单。
3. **为什么（机制）**：写出可检验的 `事件 → 利率/汇率/需求/供给/成本/产能/定价权 → 行业利润池 → 公司实际暴露 → 收入/毛利/净利 → CFO/FCF → 估值/风险` 中适用的环节；至少写清最关键的一到两个因果环节，并区分行业 Beta 与公司 Alpha。若只是注意力或短期交易情绪，写清“尚无可证实的长期现金流影响”。
4. **影响强度与时间跨度**：分别判断短期价格/流动性（当日—数周）、经营兑现（季度—两年）和长期所有者价值（五年以上、必要时20年主情景/50年压力测试）。用 `较大 / 中等 / 有限 / 待量化` 描述**有说明对象的条件性幅度**，交代根据（占收入/成本/利润或FCF的比例、订单敞口、净债务、估值久期、实际市场广度等）；缺分母或资料就写“待量化”，不对每条强行打分，也不把媒体热度、涨跌百分比等同内在价值变化。
5. **投资机会与风险（条件式）**：写“可能值得研究的受益环节/估值错位”与“受损环节/价值陷阱/反向情景”，说明机会**成立需要什么证据**、失败有什么反证。任何股票层面的价值机会还需当日可核验价格、财报/现金流及保守—基准—乐观估值区间；没有模型时写“待估值”，不得宣称低估、百分比上涨空间、必然回归或机械买卖/仓位建议。
6. **已反映多少与下一验证**：区分基本面变化、短期价格行为和“Price In”；有可靠行情才判断市场是否已预期，标明真实交易日、样本与对照；无可靠价格/估值信息写“已定价程度未判定”。写下一份一手公告、数量/价格/订单/财务/现金流或市场观察指标及期限；写出可证伪情景。不得把单个正面事实机械等同股价上涨。

## 2. 投资传导与风险的对称性

- 同一事实可以对上下游、出口商与进口商、持有现金与高杠杆公司、短期利润与长期估值产生不同方向影响。明确哪些影响是事实，哪些只是条件推论；必要时给出对冲性受益方和潜在受损方，但不得为凑字数制造虚构对手方。
- 区分**一次性事件**、周期性变化和永久性竞争结构变化。有限期新增利润必须折现且扣除CAPEX/营运资本和融资风险，不能凭一至两年景气机械上修20—50年总价值；事件也可能改变远期壁垒，但必须提供实际证据。
- 风险不仅是“股价下跌”：包括现金流消耗、融资/偿债、稀释、需求破坏、监管、订单兑现不足、估值已充分反映和流动性。既要找支持机会的证据，也要找推翻它的事实。
- 当日 A/H 尚未交易或行情滞后时，不写“今日股价已确认”“市场已充分定价”；用上一真实收盘日作背景并明确待验证。
- 影响等级是**描述具体影响的研究判断**，不是推荐榜单、保证收益或政治选择的价值排名；涉及政策只描述可核实条款、执行路径和不同群体/行业的条件影响，不将政治立场当投资事实。

## 3. 公开写作格式：首页直接能读懂影响

`## 今日全市场资讯速览`、盘中更新的新闻主列表以及 `latest/daily.md` 的每条新闻摘要，尽量采用一个独立编号条目、单个完整 Markdown 物理行，供网站现有 `section_items` 提取：

`1. **【行业】事件事实标题。** 事实（F；披露日期、来源URL）。｜影响：全市场/行业/标的各自正负或分化及传导理由（I）。｜机会：条件性受益领域及成立证据；无法确认则待验证。｜风险：主要受损方/反证。｜强度/期限：短期××、盈利××、长期待量化（标对象/依据）。｜已定价/下次验证：真实行情日或未判定；可核验指标。`

这是字段要求而非固定冗长措辞：保持摘要可读，允许合并措辞，但**不能省掉具体投资影响、潜在受益/受损、强度/期限的证据边界与主要验证**。若一条新闻没有合理可识别的投资机会，明确写“机会：暂无可证实的直接机会”，不编造相关股。新闻密集时至少提供“影响｜机会/风险｜强度/期限”三段直读摘要，把完整现金流桥、情景与来源留在本期可免费查看的全文；必要时宁可减少条数也不删掉分析。`latest/daily.md` 概述与其所指当期报告保持同一方向及证据层级，不能加入正文没有的结论。

示例（**纯假设，不是当前市场事实或具体证券观点**）：`**【农业】假设出现为期一年的天气减产。** 假设供给收缩（S）。｜影响：若售价上涨且销量下降幅度较小，特定生产者短期利润可能受益；下游采购成本可能上升（I）。｜机会：核实有真实定价权及可销售库存的企业；公司映射待验证。｜风险：减产同时减少出货、库存不足、需求下降。｜强度/期限：当年可能较大，20年价值增量待现金流模型量化。｜已定价/验证：未判定；观察实际产量、成交价格、渠道库存与FCF。` 不可用该示例替代真实资料。

## 4. 质量门槛与栏目分工

- 每条新闻至少同时具备**原始事实及日期/来源、具体影响对象与因果链、正负或不确定方向、条件性机会/风险、强度与期限的依据或待量化声明、验证/证伪**。缺其中关键环节，只能放在 `Discovery/待验证`，不得将空洞“利好某板块”“值得关注”作为正式投资映射。
- 深度研究负责详细量化情景、行业—公司盈利桥、FCFF/FCFE、债务/稀释、Price In、证伪；市场行为栏目负责已完成真实交易日的量价与广度；风险栏目突出独立风险，不把同一消息拆成多条凑数。
- 周报/月报复盘此前映射是否兑现、哪些传导断裂、影响强度是否高估；保留反例和失败历史。已有不可变历史报告不得回写，新要求只适用于后续新稿及今后的最新摘要。
