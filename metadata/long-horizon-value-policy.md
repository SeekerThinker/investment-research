# 长期所有者价值与回撤候选研究规范（Long-Horizon Owner Value）

适用于 A/H 股全市场独立日报、周报、月报及公开网站。目标是把**可持续的企业现金创造能力**与**当期证券交易价格**分开评估，发现基本面改善而价格阶段性回撤的可审计候选，同时优先识别永久性资本损失。候选不是买入建议；没有足够一手数据时必须写“暂不可估值／待验证”，不制造目标价或上涨空间。本规范与 `research-os.md`、`daily-coverage-policy.md` 的证据、日期及历史不可变纪律同时有效。

## 1. 从“买下整个公司”理解价格与价值

- 把企业想象为一项经营性资产：它未来能创造多少**可供资本提供者或股东分配的现金流**，创造现金需要多少维持性及成长性 CAPEX、营运资本和融资，竞争优势能维持多久。会计净利润、收入、市值上涨或单年景气本身都不是可直接相加的所有者回报。
- **企业价值 EV 路径**：以风险匹配的 WACC 折现 FCFF，得出经营资产价值；清楚处理非经营现金、债务、少数股东权益和其他索取权，得到普通股权益价值，再除以合理的完全稀释股数。**股权价值路径**：以股权资本成本折现 FCFE，直接得到普通股权益价值；不能混用 FCFF 与股权折现率、把债务重复扣减，或把股利/留存再投资和终值重复计入。
- 20年是长期压力测试主视角，50年是更远端的竞争寿命和残值敏感性测试，**不是宣称可精确预测未来50年**。明确分段假设（如可验证的近期、竞争均值回归的中期、成熟/衰退/清算的远期），终值只能计入一次；对几十年后规模、增长率、资本回报率和折现率做敏感性检验。若远端终值主导结果而护城河、再投资回报或生存证据不足，应降低可信度，不宣称大幅低估。
- 用相同币种、通胀口径、股份基数与估值时点比较价值和价格；A/H 两地上市时分别核对交易所、股种、汇率、流通/总股本、分红税费以及权利差异。整家公司假想收购的控制权溢价或协同不能自动加到普通流通股价值。

## 2. “短期冲击对长期价值”的增量桥

逐一拆解临时冲击带来的 `(1) 事件期间增量FCF现值 + (2) 事件结束后持续改变的长期FCF/终值现值 − (3) 额外CAPEX、营运资本、融资及尾部损失`；把基准、受益、受损情景与事实/推论/假设分别列明，绝不凭直觉固定成10%、20%或50%。

农业/种业可作**示范问题而不是未经核验的股票结论**：极端天气若只影响一至两年种子补库、价格或销售，增量收益应作为有限期现金流折现；若持续改变育种竞争力、市场份额、复购、技术壁垒、行业供需或长期气候适应需求，才可考虑持续期及终值变化。分别验证种子实际售价/销量、库存、种植面积、审批和品种表现、渠道回款、营运资本、持续研发投入。短期股价即便大涨，也不能仅凭这一个变化断言长期价值大涨或未来必然回落；检验市场是否同时重新定价其他可持续变量。

## 3. 候选发现：基本面改善 × 阶段回撤 × 成交收缩

**广泛发现、严格验证**：从公开全市场公告、财报、经营数据、行业领先指标和合法行情来源构造候选池，而不是只在既有少数监控股票中寻找。记录 universe、覆盖日期、A/H 证券代码及数据缺口；没有全市场合法数据就如实写“有限样本发现”。

每个候选分开核实三组证据：

1. **基本面改善**：可核验订单、现金回款、毛利、经营现金流、FCF、单位经济性、资本回报或稳定的领先指标。区分周期性低基数、一次性损益、会计政策、关联交易、扩产而尚未形成现金流；公司 Alpha 与行业 Beta 分开。
2. **阶段性回撤与缩量**：标明最新已完成交易日、复权调整与股数变化；核对近期高点至现价的回撤幅度、与指数/同业相对表现、回撤期间与上涨期间的成交量/成交额及20/60日可用基准。核查停牌、流动性不足、假期、除权、配售、重大公告和跨市场交易时段。缩量可能意味着抛压缓和，也可能意味着需求不足或价格尚未充分发现，**仅作为市场行为线索，绝非底部确认或价值证据**。
3. **价格与价值错位**：取得同日可核验交易价格、市值、净债务/完全稀释股数；建立有来源的保守/基准/乐观情景，披露现金流桥、折现率、增长和终值敏感性。`潜在上涨空间 = 估计每股价值 / 当前每股价格 − 1`；`相对价值安全边际 = (估计每股价值 − 当前价格) / 估计每股价值`，两者分母不同不可混为一谈。只在假设和数据足够时展示**区间**及日期；保守情景不足以覆盖价格、股权稀释或风险时不得宣称有安全边际。

## 4. 必须排查的价值陷阱与不可逆风险

债务到期/再融资、现金耗损、质押、审计保留、财报质量、应收/存货积累、持续负FCF、资本开支强度、产品替代、竞争侵蚀、监管约束、治理和少数股东风险、港股流动性及大股东融资。回撤本身可能反映基本面真实恶化；必须寻找反证和仍未发现的负面信息。把当前盈利增长与多年可持续盈利能力、现金创造能力分开，必要时作衰退/清算情景。

## 5. 可发布候选卡片与状态

只有实际取得可核验资料的标的才写入 `## 长期价值与缩量回撤观察`（日报）、周报/月报相应栏目；优先3—6个证据较全的候选，若无合格候选应明确“本期无可核实合格标的”，**不要凑数**。每条按 `1. **【长期价值观察】证券名称与代码：事实性标题。** 基本面证据及日期；回撤与缩量测量窗口/数据来源；保守/基准/乐观估值区间与关键假设（若不足则未判定）；核心价值陷阱、证伪和下次验证；来源链接。` 呈现。不得将筛选结果描述成确定上涨、回归时间、买点、赔率或收益承诺；未算出估值的可保留“待估值候选”，不要伪造百分比。

`latest/daily.md` 在确有当期事实的情况下，从本期合格候选中择取1—3条独立摘要纳入 `## 今日核心结论`，标题以 `【长期价值观察】` 开头，网站原有日报资讯流便能直接呈现并链接本期原文；避免同一候选在首页多个栏目重复。历史报告不回填；跨期变更只写新报告，已被证伪的候选保留失败记录。
