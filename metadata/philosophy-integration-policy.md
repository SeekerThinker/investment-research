# 投资思想库与研究执行的统一入口

**当前思想库版本：v0.1（编辑者提炼草案，未经所有者逐字审定）。** 本文件用于让新研究和定时任务有一个简短、稳定的入口；不将投资哲学当作市场事实，更不预设任何证券的涨跌。参阅 [`../philosophy/README.md`](../philosophy/README.md)、[`../philosophy/core-beliefs.md`](../philosophy/core-beliefs.md)、[`../philosophy/research-constitution.md`](../philosophy/research-constitution.md)、[`../philosophy/ideas.md`](../philosophy/ideas.md)、[`../philosophy/intake-and-propagation.md`](../philosophy/intake-and-propagation.md)、[`../philosophy/integration-map.md`](../philosophy/integration-map.md)、[`../philosophy/change-log.md`](../philosophy/change-log.md)。

## 新研究开工

1. 先读思想库 README、核心思想及研究宪章，再读本期任务相关的 `metadata/research-os.md`、`source-policy.md`、`daily-coverage-policy.md`、`news-investment-impact-policy.md`、`long-horizon-value-policy.md`、`market-behavior.md`、`continuity-policy.md`、`publication-policy.md`。不具有关联性的专业规范可以注明不适用，不能省略关键的证据、时间与历史不可变纪律。
2. 市场/新闻：从事实到行业及有证据的公司暴露，明确正负影响、条件性机会/风险、期限与反证；研究本期全市场而非复述旧日报。标的：研究订单、利润与现金流；估值：20年分段FCF/50年竞争寿命压力测试，核查回撤/量能和价值陷阱。
3. 新报告正文或末尾注明 `思想库依据：v0.1（提炼草案）；关联原则：Pxx；本期证据/例外/未解冲突：……`。引用的是分析方法，不是声称所有者批准每句话。若无关联原则写“未适用”并解释。**已有报告不得因此被覆盖、补写或更换日期**。
4. 事实与可复核证据优先于投资偏好。遇到新事实反驳长期假设，要在新报告记下反证并按 `philosophy/intake-and-propagation.md` 处理，不可因“违背哲学”过滤不利事实。没有可靠价格、现金流、净债务及模型时不得发布有保证的潜在涨幅。

## 每次自由讨论的变更传播

当所有者在与项目有关的对话中不定期提出思想，阅读 `philosophy/intake-and-propagation.md`，忠实归类到 ideas（探索、研究假设、明确偏好或执行要求），必要时更新 core-beliefs 和宪章；按 integration-map 检查专业规范、数据、报告模板、网站、日/周/月任务、自动检查，逐项记 `已更新 / 不适用+理由 / 待处理+原因` 于 change-log。所有者原意与编辑者推论分列；冲突留痕，已经发布的历史研报不回写。思想库版本升级后，新报告引用最新版本。

**边界**：仓库由所有者批准公开，禁止上传凭据、私密对话、个人财务信息及无再分发许可的内容。聊天不是后台监听；只有在后续对话明确关联项目、仓库连接可用且有写权限时才执行入库，失败要如实说明。自动测试只检查可机器验证的结构与引用，不宣称能自动证明投资判断正确。
