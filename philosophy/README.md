# 投资思想库 · Investment Philosophy

**性质：长期研究的上层思想与可审查原则，不是当天新闻、股票结论或交易指令。** 本目录独立于 `reports/`（有时间戳的研究事实与推论）、`data/`（机器/行情材料）、`index/` 和 `tracking/`（证据与研究状态），并处于 Git `main` 的正常版本管理中；不使用长期分支保存“另一份真理”。

## 阅读顺序与文档分工

1. [`core-beliefs.md`](core-beliefs.md)：从项目所有者在对话中提出的长期企业价值、短期市场价格、风险及研究目标抽取的**思想草案**。标注“所有者明确提出”与“据此推导、待所有者确认”，不得将我们的补充假设冒充所有者原话。
2. [`research-constitution.md`](research-constitution.md)：把思想转化为日报/市场/行业/公司/估值通用的研究检查清单和冲突处理；它约束**研究过程与表述质量**，不规定最终必须看多/看空。
3. [`change-log.md`](change-log.md)：记录提炼与未来修订的理由、版本和生效范围；不得静默覆盖已发布的历史报告。

## 层级与适用边界

`哲学（研究目的、长期视野、损失意识） → 研究宪章（过程约束） → metadata/ 中的专业方法（可操作定义） → data/index/tracking（可追溯证据） → reports（当期、可证伪结论） → latest/与网站（免费阅读呈现）`。

- 对研究过程：新工作应符合这里的长期价值、证据、风险及反证原则；如专业方法与本库出现程序性冲突，应在新报告披露并提交方法修订，不要暗中绕过。
- 对世界事实：**官方披露、真实市场数据与可复核证据优先于任何投资信念**。若事实推翻假设，须修正假设；思想库不能充当否决不利证据的权威。
- 对观点与政策：区分“我愿意采用的研究原则”和“可被证实的事实/模型假设”；不得将政治评价、个人偏好、财经叙事冒充确定的投资影响。
- 与现有 [`../metadata/research-os.md`](../metadata/research-os.md)、[`../metadata/long-horizon-value-policy.md`](../metadata/long-horizon-value-policy.md)、[`../metadata/news-investment-impact-policy.md`](../metadata/news-investment-impact-policy.md)、[`../metadata/daily-coverage-policy.md`](../metadata/daily-coverage-policy.md) 并行。细节定义仍以相应专业文档为准；本库负责说明**为什么**及跨报告必须怎样检查。

## 维护

当前为 **v0.1 提炼草案，尚不表示所有者逐字批准**。所有者提出的新思想优先记录其原意、适用条件和待验证处；编辑者补充内容明确注明为操作化建议。实质修订需修改相应文档、更新 `change-log.md`，让后续报告引用生效版本；旧报告保持原样。项目仓库公开，避免提交凭据、私密信息或无授权的第三方内容。
