# 投资思想库 · Investment Philosophy

**性质：长期研究的上层思想与可审查原则，不是当天新闻、股票结论或交易指令。** 本目录独立于 `reports/`（有时间戳的研究事实与推论）、`data/`（机器/行情材料）、`index/` 和 `tracking/`（证据与研究状态），在 Git `main` 中正常版本管理，不另以长期分支保存另一套原则。

## 阅读顺序与文档分工

1. [`core-beliefs.md`](core-beliefs.md)：所有者提出的长期企业价值、短期价格、风险、广扫描精发布，以及**投资机遇／风险规避两条主线（P10）**的意旨提炼草案；区分所有者意思与编辑者推导。
2. [`research-constitution.md`](research-constitution.md)：市场／行业／公司／估值通用研究过程与证据检查，不预设看多或看空。
3. [`ideas.md`](ideas.md)：新投资想法与状态；[`intake-and-propagation.md`](intake-and-propagation.md)：自由讨论后的收纳与同步流程；[`integration-map.md`](integration-map.md)：下游依赖；[`change-log.md`](change-log.md)：实际修改、版本和回执。

## 层级与适用边界

`哲学（长期所有者价值、损失风险、广扫描精发布与两类重点） → 研究宪章 → metadata/ 专业方法 → data/index/tracking 证据 → 不可变 reports → 可变 latest/精选摘要与免费网页`。

- 新日报后台扫描九类全市场信息，公开摘要只留约5—7个面向、通常7—10且最多12条。日报的每条显式选择**投资机遇**或**风险规避**主线，直读事实、传导、待验证的潜在预期差、成立条件或风险触发、期限与下一验证，不重复填两套空洞字段；反证和完整来源保留于免费全文。周报和月报始终独立显示，不受日报数量限制。细则见 [`../metadata/daily-coverage-policy.md`](../metadata/daily-coverage-policy.md)、[`../metadata/news-investment-impact-policy.md`](../metadata/news-investment-impact-policy.md) 和 [`../metadata/philosophy-integration.md`](../metadata/philosophy-integration.md)。
- **事实优先于信念**：正式披露、可靠行情和反证能修改观点，不得以理念排除不利材料。希望研究“重大预期差／高收益或重大损失”不等于已有任何具体证券已被证实具有这样的空间；需要可比预期、同日价格、现金流和估值区间，证据不足明确待量化。
- 与 [`../metadata/research-os.md`](../metadata/research-os.md)、[`../metadata/long-horizon-value-policy.md`](../metadata/long-horizon-value-policy.md) 协同，思想库说明研究目的，专业规范负责可执行的证据和模型边界。

## 维护

当前为 **v0.3 意旨提炼草案（v0.1为历史基线），不表示所有者逐字批准**。新明确执行要求可以收录落实，探索性想法和编辑者操作建议分开标注。任何实质变化记录于 `ideas.md` 与 `change-log.md`，逐层核对依赖；已发布历史报告不改写。公开仓库不得写入凭据、个人敏感资料或无授权材料。
