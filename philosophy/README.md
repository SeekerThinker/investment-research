# 投资思想库 · Investment Philosophy

**性质：长期研究的上层思想与可审查原则，不是当天新闻、股票结论或交易指令。** 本目录独立于 `reports/`（有时间戳的研究事实与推论）、`data/`（机器/行情材料）、`index/` 和 `tracking/`（证据与研究状态），在 Git `main` 中正常版本管理，不以长期分支保存另一套原则。

## 阅读顺序与文档分工

1. [`core-beliefs.md`](core-beliefs.md)：所有者提出的长期企业价值、短期交易价格、风险、全面扫描与精选发布的**思想草案**。区分所有者意旨与编辑者推导。
2. [`research-constitution.md`](research-constitution.md)：市场/行业/公司/估值通用的研究过程与证据检查，不预设看多看空。
3. [`ideas.md`](ideas.md)：新的投资想法与状态；[`intake-and-propagation.md`](intake-and-propagation.md)：自由讨论后的收纳与同步流程；[`integration-map.md`](integration-map.md)：下游依赖与影响检查；[`change-log.md`](change-log.md)：实际修改、版本和回执。

## 层级与适用边界

`哲学（长期所有者价值、风险、广扫描精发布） → 研究宪章 → metadata/ 专业方法 → data/index/tracking 证据 → 不可变 reports → 可变 latest/精选摘要与免费网页`。

- 新日报的后台扫描应完整，但公开当期资讯优先提炼为**5—7个面向、通常7—10条，最多12条**。每条保留投资影响、风险、期限与验证，完整证据和未入选资料仍可免费追溯。实施细则见 [`../metadata/daily-coverage-policy.md`](../metadata/daily-coverage-policy.md) 和 [`../metadata/philosophy-integration.md`](../metadata/philosophy-integration.md)。
- **事实优先于信念**：正式披露、可靠行情与反证能够修改观点，不能用个人理念排除不利材料。区分研究原则与模型假设、当期市场事实、政治评价及未经证实的叙事。
- 与 [`../metadata/research-os.md`](../metadata/research-os.md)、[`../metadata/long-horizon-value-policy.md`](../metadata/long-horizon-value-policy.md)、[`../metadata/news-investment-impact-policy.md`](../metadata/news-investment-impact-policy.md) 协作，本库说明研究为什么这样做，具体定义仍由专业规范负责。

## 维护

当前为 **v0.2 意旨提炼草案（v0.1为历史版本），尚不表示所有者逐字批准**。新的明确执行要求可入库并落实；例子、探索性观点和编辑者操作建议分别标注。任何实质变化记入 `ideas.md` 和 `change-log.md`，全面检查依赖对象；已发布的历史报告原样保留。仓库公开，禁止写入凭据、个人敏感资料或无授权第三方材料。
